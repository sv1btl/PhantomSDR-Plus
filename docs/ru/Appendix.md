# Приложение — Справочник команд

Все команды, которыми сисоп пользуется для работы станции PhantomSDR-Plus, сгруппированные по задачам, с пояснением в одну строку. Выполняются из каталога `PhantomSDR-Plus`, если в строке не сказано иное. Пошаговая ручная установка (зависимости, Node.js, OpenCL, сборка вручную) здесь не повторяется — см. [Руководство по установке](INSTALLATION.md). Последний столбец ссылается на раздел, где объясняется команда; в PDF после ссылки указан номер страницы.

## Установка и настройка станции

| Команда | Что делает | См. |
|---|---|---|
| `git clone https://github.com/sv1btl/PhantomSDR-Plus` | Загружает проект. | [README](README.md#установка) |
| `bash install.sh` | Полный установщик для Ubuntu/Debian: задаёт вопросы о станции, устанавливает, собирает. | [Руководство по установке](INSTALLATION.md#клонирование-репозитория-и-запуск-установщика) |
| `bash install_fedora.sh` | Тот же установщик для Fedora. | [Руководство по установке](INSTALLATION.md#клонирование-репозитория-и-запуск-установщика) |
| `bash install_arch.sh` | Тот же установщик для Arch Linux. | [Руководство по установке](INSTALLATION.md#клонирование-репозитория-и-запуск-установщика) |
| `bash install_opensuse.sh` | Тот же установщик для openSUSE. | [Руководство по установке](INSTALLATION.md#клонирование-репозитория-и-запуск-установщика) |
| `PHANTOM_NONINTERACTIVE=1 PHANTOM_SDR=1 ./install.sh` | Установка без вопросов (здесь для RX888 MkII); каждый вопрос получает значение по умолчанию. | [Руководство по установке](INSTALLATION.md#установка-без-присмотра) |
| `chmod +x *.sh` | Снова делает скрипты исполняемыми (например, после распаковки zip). | [Руководство по установке](INSTALLATION.md#обновление-вручную) |
| `bash configure-station.sh` | Мастер станции: задаёт вопросы, сохраняет `station.conf` и записывает по нему все файлы настроек. | [Руководство по установке](INSTALLATION.md#вопросы-о-станции) |

| `cd frontend && ./build-default.sh` | Собирает только десктопную страницу. | [Редактирование вариантов](EDITING_VARIANTS.md#6-после-правки--пересборка) |

| `bash update.sh` | Сообщает, что изменит новая версия, и спрашивает, обновлять ли. | [Руководство по установке](INSTALLATION.md#запуск) |
| `./update.sh --check` | Только отчёт, без вопросов (для cron; код выхода 10 = есть обновление). | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --apply` | Обновляет, спрашивая о файлах, которые вы правили сами. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --apply --yes` | Обновляет без вопросов; каждый изменённый вами файл сохраняется. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --apply --prune` | Также предлагает удалить файлы, убранные в основном репозитории. | [Руководство по установке](INSTALLATION.md#запуск) |
| `./update.sh --from FILE` | Берёт новую версию из `.zip`/`.tar.gz` или папки — без сети. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --ref v5.1.0` | Обновляет до тега, ветки или коммита вместо текущего дерева. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --list-excludes` | Показывает файлы, которые программа обновления никогда не трогает. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --verbose` | Показывает все файлы, а не только первые 40. | [Руководство по установке](INSTALLATION.md#другие-возможности) |
| `./update.sh --restore LAST` | Возвращает файлы, перезаписанные последним обновлением. | [Руководство по установке](INSTALLATION.md#отмена-обновления) |
| `./update.sh --restore 20260923-164530` | Возвращает файлы этого конкретного запуска. | [Руководство по установке](INSTALLATION.md#отмена-обновления) |
